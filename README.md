## Build Guide 
Building the core part of Ciallo is the same as a regular Godot project:
- Set up Godot 4.4.1 with .Net9 available. You can follow an arbitrary [video guide](https://www.youtube.com/watch?v=7nExKQn1CAw). Be careful with the version. 
- Open the `Ciallo/project.godot` file with your Godot editor, then build.
